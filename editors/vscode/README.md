# stag for VS Code

Syntax highlighting, editing support and a language server client for
stag (`.stag` files).

- Highlighting follows the lexer (`syntax/src/lexer.ml`). Quotes `.< >.` are
  `meta.quote.stag` and splices `.~` are `meta.splice.stag`, so they can be
  tinted, eg. in `settings.json`:

  ```json
  "editor.tokenColorCustomizations": {
    "textMateRules": [
      { "scope": "meta.quote.stag", "settings": { "fontStyle": "italic" } }
    ]
  }
  ```

  Highlighting is context free, so a bare type name (`int` in `x : int`) is
  coloured as a variable, while an applied one (`list[int]`) is coloured as a
  type. Semantic tokens from the language server should fix this.
- The language server is `stag lsp` (planned). Until it exists, the client
  reports once that it could not start, and formatting runs `stag fmt`.
  Syntax errors from `stag fmt` show in the status bar and the `stag` output.
- `stag.serverPath` (default `stag`, looked up on PATH) is the stag executable.
  A relative path is resolved against the workspace folder of the active stag
  document (or else of any open one), or else the first workspace folder.
- In untrusted workspaces (Restricted Mode) only highlighting and editing
  support work: neither the server nor `stag fmt` runs, and a workspace's
  `stag.serverPath` is ignored. They start once the workspace is trusted.
- `stag: Restart Language Server` restarts the server.

## Build and install

```sh
npm ci
npm run package     # stag-<version>.vsix, with the client bundled by esbuild
code --install-extension stag-*.vsix
```

Without node: `nix shell nixpkgs#nodejs_22 -c npm ...`.

## Test

```sh
./test.sh                # grammar tests, the grammar over all .stag files and
                         # against the lexer (`stag dump-tokens`), tsc
./test.sh --integration  # also the client in VS Code, against the dune build
```

The grammar source is `syntaxes/stag.tmLanguage.yaml`; `npm run build:grammar`
regenerates the JSON, which is committed. Grammar unit tests are in
`test/grammar/` (`^` lines assert the scopes of the line above), the snapshot
in `test/snap/` (update with `npx vscode-tmgrammar-snap -u 'test/snap/*.stag'`).
`node test/tokenize.js FILE` prints the tokens of a file. `test/corpus.txt`,
stag sources of the OCaml tests, is regenerated by `npm run gen:corpus`.
